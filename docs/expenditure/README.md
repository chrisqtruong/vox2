# Project expenditure

Where Vox2's Claude tokens go: day by day, by focus area (meaning check, Mac version, bug fixes, releases…), what it would cost at API prices, and how that lines up with the [roadmap](../../README.md#roadmap).

It's tracked by **Swear Jar**, a small companion project:

- **Dashboard:** [chrisqtruong.github.io/swear-jar](https://chrisqtruong.github.io/swear-jar/) (updates itself)
- **Code, setup, and how to make your own:** [github.com/chrisqtruong/swear-jar](https://github.com/chrisqtruong/swear-jar)
