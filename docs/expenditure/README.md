# Project expenditure

Where Vox2's Claude tokens go: day by day, by focus area (meaning check, Mac version, bug fixes, releases…), what it would cost at API prices, and how that lines up with the [roadmap](../../README.md#roadmap).

It's tracked by **Coin-Op**, a small companion project:

- **Dashboard:** [chrisqtruong.github.io/coin-op](https://chrisqtruong.github.io/coin-op/) (updates itself)
- **Code and setup:** [github.com/chrisqtruong/coin-op](https://github.com/chrisqtruong/coin-op)
