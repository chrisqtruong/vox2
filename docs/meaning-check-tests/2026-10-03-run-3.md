## What changed in Vox2 (Phase 1.1)

**False-alarm fixes** (run 2's two biggest causes, about 80% of its false alarms):

| Change | Why |
|---|---|
| Words that carry their own "not" count as negations: *unknown, unaware, unable, unclear, uncertain, unlikely, impossible, unavailable, lack, fail, refuse, deny, without, hardly, rarely…* | "his name is still **unknown**" ↩ "authorities do **not** know his name" was flagged; now both sides have one negation. Also catches "**lack** variety" vs "more variety". |
| "not only / not just / not merely" isn't a negation | "as well as a champion" ↩ "**not only** was he a champion" was flagged. |
| Times count as the same number: 11:00 = 11am = 11 a.m. = 11 o'clock | "Just after 11:00" ↩ "just after 11am" was flagged. |
| Digits right after letters are part of a name: COVID-19, G7, MP3 | "COVID-19" ↩ "coronavirus" was flagged. |
| A lone "one" isn't a count | "**One** of the strong points" was read as the number 1. |

Numbers glued to a word after the number still count ("30-year-old", "90-degree", "1830s"). An early version dropped them by mistake; it was caught on the development set and fixed before this run.

**Opposites list** grows from about 40 to about 90 pairs (gain/loss, ahead/behind, fast/slow, near/far, include/exclude, allow/prevent, support/oppose, all/some, alive/dead, guilty/innocent, husband/wife, men/women…).

**Phase 2 start: show what changed** ([#27](https://github.com/chrisqtruong/vox2/issues/27)). When a check fires, the word behind it is **underlined in red in the ↩ line** (the "not" that appeared, "her" for "his", "few" for "many", "52" for "15"). When the score is below 85, the hover card also lists **"didn't come back:"** with your words that are missing from the ↩ line (compared by word stem, so "testing" matches "test"). This doesn't change the score, so it isn't measured here; it was checked in the app.

## How it was done

Same method as runs 1–2 ([run 1](2026-10-03.md#how-it-was-done), [run 2](2026-10-03-run-2.md#how-it-was-done)). New:

1. **Fresh held-out set:** 80 new sentences (16 per error type), none from runs 1 or 2. The fixes were designed from run 2's false-alarm *categories* and checked only on the development set before this run.
2. **Three methods on the same translations:** run 1's method (`scoreRun1`), Phase 1 (re-scored offline from the saved text and similarity with the Phase 1 code from `main`), and Phase 1.1 (`score`). So the differences come from the methods, not from Google.

## Results: development set

For reference (tuned on these). Phase 1.1 vs Phase 1: good kept 93% vs 90%, false alarms 4% vs 7%, errors caught 75% vs 78%. The 3-point dip in errors caught is entirely errors Phase 1 caught **by accident**: planted errors flagged only because Phase 1 misread something as a number (e.g. "one"). One real catch was lost (a negation).

## What we noticed

1. **The fixes did what they were meant to.** False alarms fell back near the baseline in every language without losing any real catches on fresh sentences.
2. **Remaining false alarms** (84 of 1,760 good translations below 65):
   - Numbers (27): number words not yet handled ("**Eighteen** holes", "a couple of thousand", "four dozen"), and unit conversions. One is a real Google mistake: a good translation dropped "**9,000-year** lease", which the check rightly flagged.
   - Negation (24): negative words still missing from the list, e.g. "the windows were **unbreakable**" ↩ "the window did **not** break"; "attended to" ↩ "monitored" style rewordings.
   - Similarity alone (14), pronoun (11), opposite (6), missing (2).
3. **Pronouns are now the weakest area (49%)**: 90 of 176 swapped pronouns were missed, mostly in **Tagalog, Hindi, Urdu and Spanish**, then Japanese and Korean. Many languages don't mark he/she the way English does (or drop the pronoun), so the gender is lost on the way out and the ↩ line can't show the swap. Run 2's held-out set happened to score 70% here; with 16 sentences per error type, per-type numbers swing by several points between sets.
4. **Professional translations still raise more false alarms than Google's** (6% vs 3%): human translators reword more.
5. **Google behaved this time:** 0 back-translations in the wrong language (the retry from run 2 didn't need to fire).

## Next steps

1. **Number words:** "eighteen" at the start of a sentence, "a couple of thousand", "dozen(s)"; ignore unit conversions (°F/°C, miles/km) where both sides have a number.
2. **More negative words:** *un-…-able* words (unbreakable, unavoidable, unacceptable), and similar.
3. **Pronouns:** for languages that don't mark he/she, the round trip can't show a swap. Options: compare against the translation itself (Phase 3), or say "can't check he/she for this language" instead of implying it's fine.
4. **Phase 2 next:** highlight more than the flagged words (e.g. added content), measure whether highlights help people spot errors.
5. **Next test:** another fresh held-out set; add error types (wrong word sense, tone, tense, quantities).
