# Meaning check test — 2026-10-04, run 5 (fresh held-out set; Phase 1.2b)

**Run 5.** The first test of Phase 1.2 (numbers, "not" words, inclusive pronouns; [report](2026-10-04-phase-1-2.md), merged in [#48](https://github.com/chrisqtruong/vox2/pull/48)) on sentences **nobody had looked at**. Phase 1.2 was measured only on runs 2–3, whose held-out sentences had been read while designing it. This run checks whether those gains hold on new text, and adds a sixth error type, **gender added**, for the new inclusive pronoun check.

**Summary:** they partly didn't. On fresh sentences Phase 1.2 **caught more errors** (64.7% → 70.6%, mostly the new gender check: 9% → 40%) but **raised more false alarms** (7.1% → 8.3%), the opposite of what runs 2–3 showed. The cause was one rule: counting words like *undisturbed* or *unfamiliar* as negations. A principled fix, **Phase 1.2b**, brings false alarms to **6.9%** (below 0.4.18) while keeping nearly all the gains (69.9% caught). It was designed after looking at this run, so it needs one more fresh set to confirm ([next steps](#next-steps)).

The run also shows that **earlier phases were tuned a bit too closely to their own test sentences**: even 0.4.18's checks score worse here (7.1% false alarms, 64.7% caught) than on run 3 (4.8%, 78%). That's what fresh held-out sets are for.

## The new error type: gender added

16 sentences that state no gender, with one planted: "they" → "he" (verb kept agreeing: "they are" → "he is"), "people" → "men", "child" → "son", "parent" → "mother", "partner" → "husband", "friends" → "girlfriends". For example: *"Hostels cater primarily to young people – a typical guest is in **his** twenties"* (was *their*). This is what misgendering looks like on the way in; the check should notice that the ↩ line says something your text didn't.

## How it was done

Same method as runs 2–3 ([run 3](2026-10-03-run-3.md#how-it-was-done)). New:

1. **A fresh held-out set** from FLORES-200 sentences never used before.
2. **Four methods on the same translations** (`tools/meaning-bench/compare.mjs`): run 1's method, 0.4.18's word checks and Phase 1.2b (both re-scored from the saved similarity), and Phase 1.2 as the bench ran it. The offline re-score reproduces the bench's saved scores exactly (0 of 4,488 differ).

## What went wrong in Phase 1.2, and the fix (Phase 1.2b)

Phase 1.2's new false alarms on fresh sentences (31 rows) came from two rules:

**1. Counting built negative words as negations (17 rows).** Phase 1.2 counted words like *unharmed*, *treeless*, *immoral* as a "not", so that "not hurt" ↩ "unharmed" would balance. But translations swap these freely with plain words that mean the same: "left **undisturbed**" ↩ "remained **intact**", "**new** to you" ↩ "**unfamiliar**", "bare backs" ↩ "**unsaddled**". Each swap tipped the count and looked like a "not" appearing.

**Fix:** two kinds of negative words. *Plain* negations (not, never, can't, without, lack…) change the meaning when one appears or disappears, as before. *Built* negatives (un-…, -less, im-/in-… words) never raise a flag on their own; they only count to **cancel** a plain negation on the other side. So "not hurt" ↩ "unharmed" still balances, and "undisturbed" ↩ "intact" no longer fires. The cost: "unbreakable" ↩ "broke" (a real flip with no plain "not") isn't caught.

**2. A gendered word where your text already gave the gender (some of 14 rows).** "One of the richest **people**, Allen… **his** wealth" ↩ "one of the richest **men**" was flagged as a gender appearing. But the text had already said *his*. **Fix:** the neutral-word → gendered-word check (partner → wife) only fires when your text states no gender at all.

The other new pronoun flags are real: Google's ↩ line turned submarines ("**they** travelled on the sea") into "**she**", the kind of gender appearing the check is for.

## What we noticed

1. **Fresh held-out sets matter.** Phase 1.2 looked like a clean win on runs 2–3 and wasn't on new text. Rules that come from examples you've read fit those examples better than the world.
2. **Earlier phases drift the same way.** 0.4.18's numbers on fresh sentences (7.1% false alarms, 65% caught) are worse than on the sets it was built on (4.8%, 78%). The honest current figure for the meaning check is about **7% false alarms and 70% errors caught (C-)**.
3. **The inclusive check works but is limited by the round trip.** "Gender added" errors caught went from 9% to 40%; the rest are lost on the way out (many languages don't mark it: Tagalog *siya*, Hindi *vah*), so the ↩ line can't show them.
4. **Numbers are now the largest source of false alarms** (53 of 2,112 good translations). Mostly the ↩ line *adding* a count your text only implies: "Fatih Erkoç and Müslüm Gürses" ↩ "**two** singers"; "one fencer dueling another" ↩ "**two** players"; "right triangles" ↩ "**three** sides". Also "two decades" ↩ "20 years", "6 by 6 cm" ↩ "6x6 cm", "1st" ↩ "first".
5. **Opposites (58%) and he ↔ she (44%) remain the weakest planted errors.**

## Next steps

1. **Confirm Phase 1.2b on a second fresh set** (run 6): 96 more unused FLORES sentences; about 45 minutes.
2. **Numbers:** an extra small count in the ↩ line that your text implies (two names → "two singers"); "decades"; "6 by 6" = 6x6; "1st" = first. Tune on the development set only.
3. **Phase 3** for opposites, pronouns and gender: compare your text with the translation directly instead of only through the round trip.
