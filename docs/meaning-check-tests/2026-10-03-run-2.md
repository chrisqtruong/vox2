# Meaning check test — 2026-10-03, run 2 (Phase 1: targeted checks)

**Run 2.** Measures Phase 1 of the meaning-check roadmap: targeted checks for the errors run 1 showed the similarity score misses ([#28](https://github.com/chrisqtruong/vox2/issues/28)). First run with a **held-out set**.

**Summary:** on 80 held-out sentences in 11 languages, Phase 1 catches **78% of meaning errors (was 34%)** and **misses 22% (was 66%)**, at the cost of slightly more false alarms on good translations (**7%, was 3%**). Flipped negations go from 27% to 83% caught, swapped pronouns from 10% to 70%, opposite words from 6% to 66%, dropped clauses from 27% to 72%. Changed numbers stay at 98%. Overall grade moves from **F to C**.

## What changed in Vox2 (Phase 1)

Run 1 found that the similarity score barely reacts when the meaning flips ("was chosen" vs "was not chosen" both score 100), but that the flip is usually visible in the ↩ back-translation. Phase 1 adds plain word checks that compare your text with the ↩ line. When one fires, the score is capped at 60 ("check the details") and the hover card says what changed:

| Check | Fires when |
|---|---|
| negation | the number of negation words (not, no, never, can't…) changes between odd and even ("without" excluded) |
| pronoun | your text uses only he/his/him and the ↩ line has she/her (or the reverse) |
| opposite | one side of an opposite pair (left/right, many/few, increase/decrease… ~40 pairs) turns into the other |
| date | a different month or weekday |
| missing | your text has 8+ words and the ↩ line is under 60% as long |
| number | (existing) the numbers differ; now "two" counts as 2 |

Word lists are English, so the checks apply when your language (the ↩ line's language) is English. Other languages keep the number check only.

## How it was done

Same method as [run 1](2026-10-03.md#how-it-was-done): for each language, Google translates the correct and the corrupted English, then translates all three translations (professional, Google-correct, Google-corrupted) back into English, and Vox2's `matchScore()` scores each against the correct English.

New in this run:

1. **Held-out set.** The 40 run-1 sentences were the **development set**: the checks were designed and tuned only on run 1's saved results for them. 80 **new** sentences (16 per error type, different random seed) were held out and not looked at until the checks were final. The headline numbers are from the held-out set.
2. **Before/after on the same translations.** Each pair records `scoreRun1` (run 1's method: similarity, capped at 60 when the digits differ) and `score` (Phase 1). Both come from the same Google output, so the difference is the method, not Google.
3. **Saving after each language**, so an interrupted run resumes.
4. **A language check on back-translations** (see Data problem below).

Tuning on the development set (run 1's data), in order:
- A "content words kept" check for dropped clauses was tried first: it flagged 5% of good translations and caught only 16% of dropped clauses, so it was replaced by the length check (60%: flagged no good translations, caught 70%).
- "without" was removed from the negation words: "without your knowledge" often comes back as "unknowingly".

## Data problem found and fixed

In the first pass, Google returned **195 "back into English" translations in Japanese or garbled mixed text** (all 120 professional Spanish ones and 75 professional Chinese ones; e.g. "ノースカロライナzhou シャーロット…"). Those pairs compare English with Japanese, so they scored low and made Spanish and Chinese look broken (and made the "missing" check look like it caused false alarms). Run 1 had none.

Fix: the test now checks that every back-translation into English is mostly English letters, retries failures one at a time, and logs any that still fail. Spanish and Chinese were re-run; the final data has **0** non-English back-translations. Earlier analysis of the bad pass is discarded.

## What we noticed

1. **The checks work as intended and generalize.** Errors caught more than doubled in every language (lowest: Tagalog 68%, highest: Arabic 88%), and the same 78% on development and held-out sentences.
2. **The cost is a few more false alarms**, mostly from two sources (held-out, 122 of 1,760 good translations below 65):
   - **Negation (58):** fair rewordings that add or drop a negation word: "his name is still **unknown**" ↩ "authorities still do **not** know his name"; "as well as a champion" ↩ "**not only** was he a champion".
   - **Numbers (41):** times and names that look like numbers: "11:00" ↩ "11am", "COVID-19" ↩ "coronavirus", "**One** of the strong points" read as the number 1.
   - Similarity alone: 15 (as in run 1).
3. **Professional (human) translations raise more false alarms than Google's** (9% vs 4%): human translators reword more, and the ↩ line is a Google translation of their wording.
4. **What's still missed (22%)**, by type: opposites 59, pronouns 53, dropped clauses 49, negations 30, numbers 4 (of 176 each).
   - Opposites not on the list ("old people" for "young people", "some" for "few"), or the ↩ line uses a different word for the flipped side.
   - Pronouns in languages without he/she (Chinese, Japanese, Korean, Tagalog, Urdu…): the gender is lost going out, so the ↩ line can't show it.
   - Negations Google expressed with a word, not "not": "are not getting more variety" ↩ "**lack** variety".
   - Some planted errors read oddly in English ("are not unsure", "not never good") and Google smoothed them into the correct meaning, so the "bad" translation isn't actually wrong. These count as misses but aren't real failures.
5. **Google occasionally answers in the wrong language** (Data problem above). Worth guarding against in the app too: a ↩ line in the wrong language should not be scored.

**Overall:** a real step up. "Meaning kept" is now wrong about 1 time in 5 for these error types, down from 2 in 3. Still not strong enough for the "check that it came out right" headline; Phase 2 and 3 target the rest.

## Next steps

1. **Fix the known false alarms** (small): treat "unknown / unable / un-…" and "not only" as non-flips; ignore times ("11:00" = "11am"), and numbers inside names ("COVID-19"); don't read "one" as a number when it isn't counting.
2. **Grow the opposites list**, and look for lexical negations ("lack", "fail to", "refuse") in the ↩ line.
3. **Show what changed** ([#27](https://github.com/chrisqtruong/vox2/issues/27)): highlight the differing words, so the remaining misses are easy to spot.
4. **Other languages:** word lists for your language when it isn't English (Vietnamese first).
5. **Next test:** measure these on a **fresh** held-out set (new sentences), and add error types (wrong word sense, tone, tense, quantities).
