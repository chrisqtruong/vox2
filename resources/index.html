extras under the translation

shows how to say the translation when it's written in another alphabet: Chinese (pinyin), Japanese, Korean, Russian, Thai, Arabic, Hindi and so on. Vietnamese, Spanish and other languages already in Latin letters don't need it, so nothing shows for them.

translates the result back into your language, shown as a faint ↩ line under it. if that line doesn't say what you meant, the translation probably doesn't either. handy before sending a message in a language you can't fully read.

adds a "92% match" tag to the ↩ line. it compares meaning, not exact words, so a reworded but faithful translation still scores high. runs on this computer with a small model: a one-time ~120 MB download, unloaded after 5 minutes unused.

permissions

macOS asks for each of these on its own. allow them all here, once, and Vox2's shortcuts, dictation and snip work from any app.

    restart Vox2 so the new permissions take effect

    in System Settings, switch Vox2 on. if it's already on but this still says needed, select Vox2, remove it with −, and add it again with + (each new build of Vox2 counts as a new app).
